# FinTech 545 - Assignment 1

This directory contains the complete, reproducible submission for Assignment 1.

## Contents

- `Assignment1_Report.pdf` - written responses and results.
- `report.qmd` - editable Quarto source for the report.
- `analysis.py` - all calculations, model fitting, tables, and figures.
- `problem1.csv` through `problem5.csv` - input data supplied with the assignment.
- `figures/` - figures generated by `analysis.py`.
- `tables/` - machine-readable result tables generated by `analysis.py`.
- `results.json` - all reported numerical results in one machine-readable file.
- `requirements.txt` - Python package requirements.

## Reproduce the analysis

From this `Assignment1` directory, create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
```

Run every calculation and regenerate all figures and tables:

```bash
python3 analysis.py
```

The script prints the results to the terminal and writes `results.json`, the
CSV files in `tables/`, and the PNG files in `figures/`.

## Rebuild the PDF

Install [Quarto](https://quarto.org/) if it is not already available. Then run:

```bash
quarto render report.qmd
```

The report uses Quarto's bundled Typst engine, so a separate LaTeX installation
is not required.

## Notes on conventions

- Problem 1 uses central moments with denominator `n` and reports excess
  kurtosis (ordinary kurtosis minus 3), matching the course convention.
- AICc is calculated as
  `AIC + (2*k^2 + 2*k)/(n - k - 1)`.
- The Student-t regression reports its scale parameter and degrees of freedom;
  scale is not the same as standard deviation.
- Problem 4 uses the sample covariance matrix with denominator `n - 1`.
- Problem 5 fits Gaussian AR/MA models by exact state-space maximum likelihood
  with a constant and an innovation variance.
